# TaskFlow — Student Task Manager

A simple and responsive task management web application that helps students organize daily activities, track pending tasks, and monitor completed tasks.

## Features

- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- View total, completed, and pending task counts.
- Automatically save tasks using browser LocalStorage.
- Retain tasks after refreshing the browser.
- Responsive user interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- Git and GitHub

## How to Run

1. Clone or download this repository.
2. Open the project folder in Cursor or VS Code.
3. Open `index.html` in your browser.

Alternatively, run a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
